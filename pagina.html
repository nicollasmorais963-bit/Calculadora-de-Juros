Juros Simples e Juros Compostos

Juros Simples

Os juros simples são calculados apenas sobre o valor inicial da aplicação ou dívida.

J = C × i × t
  • J = juros
  • C = capital inicial
  • i = taxa de juros
  • t = tempo

Exemplo:

Um capital de R$1000 aplicado a uma taxa de 10% ao mês durante 3 meses:

J = 1000 × 0,10 × 3 = R$300

Montante final:

M = C + J = 1000 + 300 = R$1300

Juros Compostos

Os juros compostos são calculados sobre o valor atualizado a cada período.

M = C × (1 + i)t
  • M = montante final
  • C = capital inicial
  • i = taxa de juros
  • t = tempo

Exemplo:

Um capital de R$1000 aplicado a 10% ao mês durante 3 meses:

M = 1000 × (1 + 0,10)3
M = 1000 × 1,331 = R$1331

Nesse caso, os juros rendem sobre os juros anteriores.
